# UP-01 — Cập nhật app Android ngay trong app (plugin AppUpdate + banner báo bản mới)
Loại: code. Rủi ro: cao. Khó: có. Worker: theo đợt. Base: factory. Milestone: phát hành APK tự động.

## Mục tiêu

Hiện tại muốn lên bản APK mới, Curtis phải vào Cài đặt › Kiểm tra cập nhật, bấm link, trình duyệt tải file, tự mở file để cài. Khi xong task: mở app (vỏ Android) mà có bản mới → app tự hiện banner "Có bản app mới", bấm **Cập nhật** → app tự tải (thấy tiến độ %) → hộp cài của Android hiện ra → bấm **Cài đặt** là xong. Android không cho app cài ngoài Play Store tự cài lặng lẽ, nên bước bấm "Cài đặt" của hệ thống là bắt buộc.

## Bối cảnh

- Phát hành: CI `.github/workflows/android-apk.yml` (Lead đã làm) build APK, tải lên Supabase Storage production và ghi `app-releases/latest.json`. Đọc đầu file workflow để hiểu dữ liệu.
- Kiểm cập nhật hiện có: `src/features/settings/route.tsx` (`checkApk`, đọc `/android-app-version.json`, bấm thì `window.location.href = url`). Banner mẫu phong cách: `src/app/UpdatePrompt.tsx` (bản mới của web), gắn ở `src/app/layout.tsx`.
- Plugin mẫu phong cách: `android-app/android/app/src/main/java/vn/sokhach/crm/*Plugin.java` (`AppInfoPlugin` trả `versionCode`), đăng ký trong `MainActivity.java`. Manifest đã có `FileProvider` (`${applicationId}.fileprovider`, `res/xml/file_paths.xml`).
- Máy chủ Factory **không có** Android SDK: Java không compile được ở đây (CI GitHub sẽ compile sau khi Curtis push). Viết đúng API Capacitor 8 + Android SDK 36 (minSdk 24), cẩn thận như VN-02 (`tasks/done/VN-02.md`).

## Hợp đồng (không được đổi — `docs/ARCHITECTURE.md` §7)

- Nguồn phiên bản: `https://nrqccwamwctihivpxjww.supabase.co/storage/v1/object/public/app-releases/latest.json` = `{versionCode, versionName, url, sha256, size, notes, publishedAt}`. Đọc lỗi/không có → thử `/android-app-version.json` (không có `sha256`). Cả hai lỗi → không báo gì (không phải "đang ở bản mới nhất").
- `Capacitor.Plugins.AppUpdate`: `canInstall()` → `{allowed}` · `openInstallSettings()` · `install({url, sha256?, versionCode})` → resolve `{started: true}` khi hộp cài đã mở · sự kiện `progress {downloaded, total}` · reject **mã** (`reject(code, code)` như VN-02) `install_not_allowed` · `download_failed` · `checksum_mismatch` · `busy`.
- `AppInfo.get()` giữ nguyên.

## Luật

1. Chỉ báo khi `latest.versionCode > versionCode đang cài` và có `url`. Chỉ trong vỏ Android; web thường không hiện gì.
2. Kiểm khi mở app và khi app quay lại (`crm:resume`), tối đa 1 lần / 6 giờ. "Để sau" ẩn banner của **đúng versionCode đó** 24 giờ.
3. Native: tải bằng HTTPS vào bộ nhớ riêng của app (không cần quyền bộ nhớ), có `sha256` thì kiểm, sai → xoá file + `checksum_mismatch`. Chỉ chấp nhận `url` https thuộc `nrqccwamwctihivpxjww.supabase.co` (chặn cài APK lạ). Mở hộp cài qua `FileProvider`. Chưa được phép cài từ app này → `install_not_allowed`; web hướng dẫn 1 câu + nút mở màn cho phép (`openInstallSettings`), quay lại thì bấm Cập nhật lần nữa.
4. Thêm quyền `REQUEST_INSTALL_PACKAGES` vào manifest. Tăng phiên bản lên `versionCode 8` / `versionName "1.7"`.
5. Thiếu plugin `AppUpdate` (APK ≤1.6) → bấm Cập nhật mở `url` như cũ (trình duyệt tải). Bản 1.6 đang dùng phải cập nhật lên 1.7 được bằng đường này.
6. Đang tải: banner hiện % và khoá nút; lỗi → 1 câu tiếng Việt dễ hiểu + "Thử lại". Không chặn thao tác khác trong app.
7. Cài đặt › Kiểm tra cập nhật dùng cùng logic (cùng nguồn, cùng nút Cập nhật).

## Phạm vi

Được sửa/tạo: `android-app/android/app/src/main/java/vn/sokhach/crm/**`, `android-app/android/app/src/main/AndroidManifest.xml`, `android-app/android/app/src/main/res/xml/file_paths.xml`, `android-app/android/app/build.gradle` (chỉ 2 dòng phiên bản), `src/features/settings/**`, `src/app/layout.tsx` (chỉ gắn banner), `src/app/` file mới cho banner/logic cập nhật app. Test mới trong `tests/**` hoặc `src/**/*.test.ts(x)`.

## PHẢI

- Unit test: so phiên bản (7 vs 8 → báo; 8 vs 8 → không), nguồn dự phòng, đọc lỗi cả hai → không báo, "Để sau" theo versionCode + 24 giờ, giới hạn 6 giờ, có/không plugin, mã lỗi → câu tiếng Việt.
- E2E 360/1280 sáng/tối: giả `window.Capacitor` (`isNativePlatform`, `nativePromise`) + chặn route latest.json → banner hiện, bấm Cập nhật thấy %, xong; trường hợp `install_not_allowed` hiện hướng dẫn.
- Test tĩnh Java (như `tests/android/speech-input.test.ts`): plugin tên `AppUpdate`, đủ phương thức, đăng ký trong `MainActivity`, có quyền manifest, kiểm host URL, `reject(code, code)`.

## CẤM

- Tự cài không qua hộp cài hệ thống; tải/cài APK từ host khác; ghi APK ra bộ nhớ chung.
- Sửa `.github/**`, `public/android-app-version.json`, `src/data/**`, `src/app/UpdatePrompt.tsx` (bản mới web — luồng khác).
- Banner che thanh điều hướng dưới hoặc nút chính của màn.
