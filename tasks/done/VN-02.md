# VN-02 — Vỏ Android: plugin SpeechInput nhận giọng nói tiếng Việt, trả chữ ngay khi nói
Loại: code. Rủi ro: cao. Khó: có. Base: factory. Milestone: góp ý 26/10.

## Mục tiêu

Trong app Android (vỏ Capacitor, D-002), WebView không có Web Speech nên ghi chú giọng nói phải đợi bấm dừng mới có chữ. Thêm plugin native `SpeechInput` dùng bộ nhận giọng có sẵn của Android (`android.speech.SpeechRecognizer`, tiếng Việt `vi-VN`) để web nhận **chữ tạm liên tục** trong lúc nói. Curtis duyệt 26/10 (cài lại APK). Phía web làm ở VN-01, song song.

## Bối cảnh

- Plugin có sẵn để làm mẫu phong cách: `android-app/android/app/src/main/java/vn/sokhach/crm/*Plugin.java`, đăng ký trong `MainActivity.java`. Quyền `RECORD_AUDIO` đã có trong `AndroidManifest.xml` (chưa xin lúc chạy).
- Máy chủ Factory **không có** Java/Android SDK: không build được ở đây. Curtis build APK trên Mac bằng `android-app/build-apk.sh`. Vì vậy code phải viết cẩn thận theo API Capacitor 8 (`@CapacitorPlugin`, `@Permission`, `notifyListeners`, `PluginCall`) và Android `SpeechRecognizer`.

## Hợp đồng (không được đổi — `docs/ARCHITECTURE.md` §7)

`Capacitor.Plugins.SpeechInput`:
- `available()` → `{ available: boolean }` (máy có dịch vụ nhận giọng).
- `start({ lang?: string })` (mặc định `vi-VN`): xin quyền micro nếu chưa có; resolve khi bắt đầu nghe. Reject mã `not_allowed` (từ chối quyền) · `unavailable` · `busy` (đang nghe).
- `stop()`: dừng nghe; resolve `{ text }` = toàn bộ chữ chốt của phiên.
- Sự kiện (`addListener`): `partial { text }` = toàn bộ chữ của phiên tới lúc này (chữ đã chốt + chữ tạm đang nói, **không** chỉ đoạn mới); `end { text }` khi phiên kết thúc vì bất kỳ lý do gì; `error { code }` với `code` ∈ `not_allowed` · `unavailable` · `no_speech` · `busy` · `other`.

## Luật

1. Nghe liên tục tới khi web gọi `stop()`: Android tự dừng sau khoảng lặng → plugin tự mở lại phiên con và **cộng dồn** chữ, không mất, không lặp. Không có tiếng trong 60 giây liền → tự kết thúc, phát `end`.
2. Chạy trên luồng chính (SpeechRecognizer bắt buộc); huỷ recognizer khi dừng / khi Activity bị huỷ.
3. Không gửi âm thanh hay chữ đi đâu khác ngoài trả về web. Không lưu file âm thanh.
4. Không làm hỏng các plugin và luồng Back hiện có.
